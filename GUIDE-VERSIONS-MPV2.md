# Guide des Versions MPV2

## 📦 Deux versions disponibles

Le calculateur MPV2 est disponible en deux versions pour répondre à différents besoins :

---

## Version 1 : Standard (mpv2-calculateur-absenteisme.html)

### 🎨 Caractéristiques

- **Style** : Professionnel et informatif
- **Couleurs** : Bleu médical classique avec accents verts
- **Design** : Riche en informations, tableau détaillé
- **Public cible** : Professionnels RH et santé au travail
- **Émojis** : Présents dans les titres
- **Densité d'information** : Élevée

### ✨ Points forts

- Affichage complet des statistiques nationales
- Informations détaillées directement visibles
- Tableau exhaustif des secteurs
- Interprétation textuelle détaillée
- Parfait pour une analyse approfondie

### 📱 Utilisation recommandée

- Intégration dans un portail RH
- Outil d'analyse interne
- Rapports détaillés
- Consultation par des experts

## Version 2 : Design Épuré (mpv2-calculateur-absenteisme-design.html) ⭐

### 🎨 Caractéristiques

- **Style** : Moderne et minimaliste
- **Couleurs** : Palette douce et professionnelle
- **Design** : Épuré, aéré, espaces blancs généreux
- **Public cible** : Grand public et dirigeants
- **Typographie** : Inter (police moderne Google Fonts)
- **Densité d'information** : Optimale

### ✨ Points forts

- Design ultra-moderne avec dégradés subtils
- Interface épurée et élégante
- Typographie premium (Google Fonts - Inter)
- Animations fluides et professionnelles
- Hiérarchie visuelle optimale
- Meilleure lisibilité
- Expérience utilisateur premium
- Adapté aux sites corporates haut de gamme

### 🎯 Design System

#### Palette de couleurs
```
Primaire : #0066cc → #004a99 (dégradé)
Accent : #00a651 (vert success)
Warning : #ff8c00 (orange)
Danger : #dc3545 (rouge)
Backgrounds : #ffffff, #f8fafc, #f1f5f9
Texte : #1e293b, #64748b, #94a3b8
```

#### Typographie
- **Police** : Inter (Google Fonts)
- **Poids** : 300, 400, 500, 600, 700
- **Échelle** : Harmonieuse et moderne
- **Espacement** : Letterspacing optimisé

#### Espacements
- Cards : 40px padding
- Grid gaps : 40px
- Border radius : 12px, 16px, 20px
- Ombres : Multi-niveaux (sm, md, lg, xl)

#### Animations
- Transitions : cubic-bezier(0.4, 0, 0.2, 1)
- Hover states : Transform + Shadow
- Fade in : Animation d'apparition
- Progress bars : 0.8s ease

## 🎯 Quelle version choisir ?

### Choisissez la **Version Standard** si :

- ❓ Vous avez besoin d'un maximum d'informations visibles
- ❓ Votre audience est composée d'experts RH
- ❓ Vous préférez un style classique et sobre
- ❓ Vous voulez minimiser les dépendances externes

### Choisissez la **Version Design Épuré** si : ✅

- ✅ Vous voulez un design moderne et premium
- ✅ Votre site a une identité visuelle haut de gamme
- ✅ Vous visez le grand public et les dirigeants
- ✅ Vous voulez **impressionner** vos visiteurs
- ✅ Vous intégrez sur **medicat-partner.fr** (RECOMMANDÉ)
- ✅ L'expérience utilisateur est prioritaire
- ✅ Vous voulez un outil de démonstration commercial

## 🎨 Personnalisation

### Version Design Épuré

Pour adapter les couleurs à votre charte :

```css
:root {
    --primary: #0066cc;        /* Votre couleur principale */
    --accent: #00a651;         /* Votre couleur d'accent */
    --primary-dark: #004a99;   /* Variante foncée */
}
```

### Version Standard

Même principe, variables CSS facilement modifiables en début de fichier.

## 🆘 Support et maintenance

### Mise à jour des données

Les deux versions utilisent les mêmes données sources. Pour mettre à jour :

1. Modifier les objets JavaScript :
   ```javascript
   const sectorData = { ... }
   const categoryData = { ... }
   const nationalAverage = 4.41
   ```

2. Mettre à jour le footer avec les nouvelles dates

3. Documenter les changements dans SOURCES-MPV2.md

### Fréquence recommandée

- **Trimestrielle** : Vérification des sources
- **Annuelle** : Mise à jour complète
- **Au besoin** : Corrections de bugs
