# Sources détaillées - MPV2 Calculateur d'Absentéisme

## 📚 Documentation complète des sources utilisées

Ce document détaille toutes les sources de données utilisées dans le calculateur MPV2, avec les liens directs, les dates de publication et les données extraites.

---

## 1. Observatoire de l'absentéisme APICIL 2024

**URL** : https://pro.apicil.com/prevoyance/taux-absenteisme-france/

**Organisme** : Groupe APICIL - Observatoire des arrêts de travail

**Date de publication** : 2024

**Fiabilité** : ⭐⭐⭐⭐⭐ (Source professionnelle reconnue)

### Données extraites :
- **Taux d'absentéisme moyen France 2024** : 4,41%
- **Durée moyenne des arrêts** : 21,5 jours
- Analyse des tendances et évolutions

### Utilisation dans MPV2 :
- Moyenne nationale de référence
- Statistiques générales affichées

---

## 2. Baromètre Diot-Siaci 2024-2025

**URL** : https://diot-siaci.com/fr/absenteisme-les-tendances-2025/

**Organisme** : Diot-Siaci - Cabinet de conseil et courtage en assurances

**Date de publication** : Avril 2025 (pour les données 2024)

**Fiabilité** : ⭐⭐⭐⭐⭐ (Baromètre annuel reconnu)

### Données extraites :

#### Taux global :
- **Taux d'absentéisme 2024** : 4,84%
- **Taux d'absentéisme 2023** : 5,06%
- **Évolution** : -0,22 points (baisse pour la première fois)

#### Taux par secteur :
- **Santé** : 8,30%
- **Commerce** : 6,23%
- **Transport/Logistique** : 5,40%

### Utilisation dans MPV2 :
- Données sectorielles principales
- Comparaisons par secteur d'activité

## 3. Étude WTW (Willis Towers Watson) 2024

**URL** : https://www.wtwco.com/fr-fr/news/2024/09/l-absenteisme-des-salaries-francais-du-secteur-prive-flechit-pour-la-premiere-fois-depuis-2016

**Organisme** : Willis Towers Watson - Leader mondial du conseil en entreprise

**Date de publication** : Septembre 2024

**Fiabilité** : ⭐⭐⭐⭐⭐ (Étude internationale reconnue)

### Données extraites :

#### Taux par secteur (2023 vs 2022) :
- **Santé humaine et action sociale** : 7,56% (vs 8,32% en 2022)
- **Hébergement et restauration** : 7,39% (vs 7,5% en 2022)
- **Transport et entreposage** : 6,18% (vs 6,84% en 2022)

### Utilisation dans MPV2 :
- Données sectorielles complémentaires
- Validation croisée des données Diot-Siaci

---

## 4. Baromètre Ayming & AG2R LA MONDIALE 2024-2025

**URL Baromètre 2025** : https://www.ayming.fr/insights/barometres-livres-blancs/barometre-de-labsenteisme-et-de-lengagement/

**URL Communiqué 2024** : https://presse.ag2rlamondiale.fr/actualites/ayming-et-ag2r-la-mondiale-devoilent-les-premiers-chiffres-de-leur-16e-barometre-de-labsenteisme-r-et-de-lengagement-2024-1955-3a203.html

**Organismes** : Ayming (conseil en performance) & AG2R LA MONDIALE (groupe de protection sociale)

**Date de publication** : 17ème édition - 2025

**Fiabilité** : ⭐⭐⭐⭐⭐ (Baromètre de référence national)

### Données extraites :

#### Taux par catégorie socioprofessionnelle (2024) :
- **Ouvriers** : 7,77%
- **Employés administratifs et agents de service** : 6,15%
- **Professions intermédiaires** : 4,70%
- **Cadres** : 2,29%

#### Observations importantes :
- Les non-cadres sont près de **3 fois plus absents** que les cadres
- Les pathologies psychologiques sont les **premières causes d'arrêts longs** (>90 jours)
- Focus sur la fatigue, dépression, burn-out

### Utilisation dans MPV2 :
- Données par catégorie socioprofessionnelle
- Comparaisons par profil d'emploi

## 📊 Méthodologie de consolidation des données

### Principe de sélection des sources

1. **Fiabilité** : Organismes reconnus et établis
2. **Actualité** : Données 2024-2025 uniquement
3. **Méthodologie** : Échantillons représentatifs
4. **Transparence** : Sources publiques et vérifiables

### Traitement des divergences

Lorsque plusieurs sources fournissent des données différentes pour un même secteur :

- **Priorité aux données les plus récentes** (2024-2025)
- **Moyenne pondérée** si nécessaire
- **Source principale** : Diot-Siaci (spécialiste de la prévoyance)
- **Validation croisée** : WTW et Ayming

### Données estimées

Certains secteurs utilisent des **moyennes sectorielles estimées** basées sur :
- Les données historiques
- Les moyennes des secteurs similaires
- Les tendances observées

**Secteurs avec données estimées** :
- Administration publique : 5,20% (basé sur données historiques fonction publique)
- Industrie manufacturière : 4,80% (moyenne sectorielle)
- Construction : 4,50% (moyenne sectorielle)
- Services aux entreprises : 3,90% (moyenne sectorielle)

## 📝 Notes juridiques

### Droits d'utilisation des données

- Les données utilisées sont issues de **publications publiques**
- Utilisation à des fins d'**information et de calcul** uniquement
- **Citation systématique** des sources dans le calculateur
- Respect des **droits d'auteur** des organismes producteurs

### Avertissement

Les données fournies le sont à **titre indicatif** et ne se substituent pas à une analyse personnalisée par un expert en santé au travail. Pour une analyse approfondie de votre situation, consultez Medicat Partner ou un spécialiste qualifié.
